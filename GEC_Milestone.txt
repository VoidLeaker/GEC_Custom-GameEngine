New Functionality
-----------------

- Collision detection through the collision data class by using rectangle shape

	- Animation manager: It handles all animation set for the sprites
	- Graphic manager: It handles all graphic related such as rendering the player and playing the animation
	- All managers above are using singleton patterns.
